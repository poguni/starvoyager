- **S08 하늘**: 이미 정한 대로 실제 별 위치·곡선 지평선·은하수 유지.

## 3. 3D 시각 품질 계획
- 태양 빛무리: 지금은 그림 한 장(스프라이트)만 있음 → 태양에만 걸리는 블룸(UnrealBloomPass, three 안에 포함, CDN 아님)을 더하고 스프라이트는 약하게. ?fx=off·?quality=low에서는 끔.
- 지구 대기광·명암 경계: 가장자리 빛 두께와 밤 쪽으로 넘어가는 경계를 조금 더 부드럽게.
- 별 배경: 무작위 점 3500개 → 실제 밝은 별 목록(이미 저장소에 있는 905개)으로 밝기별 크기·색을 주고, 어두운 별을 더함. 은하수는 북쪽 밤하늘처럼 점으로 그린 옅은 띠.
- 장면 전환: 크기 비교 실험실·북쪽 밤하늘로 바뀔 때 지금은 바로 바뀜 → 0.4초 어두워졌다 밝아지는 페이드(착륙 때 쓰는 막 재사용).

## 4. 움직임 줄이기
- 지금도 흔들림(틀린 칸·카드·별, 착륙 중 HUD)·도장·발견 카드의 움직임은 꺼짐.
- 더할 것(큰 이동 줄이기): 천체로 날아가는 비행을 2~3초 → 1초로 줄이고, 도감 펼침에 따른 화면 구도 이동은 바로 맞춤. 도감 패널 미끄러짐과 끌어다 놓기 정답 이동(1초)은 페이드로 바꿈.
