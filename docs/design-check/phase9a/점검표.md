## 시안과 같은 것
진행 표시와 점, 질문 크기, 보기(번호 원·'틀렸어요'·'정답' 표시), 오답 힌트 상자, "직접 관찰한 뒤 답을 다시 골라요."와 확인 도구 아이콘, 착륙하기 버튼 강조, 정답 배너, 정답 설명 상자, 정답 공개 상자("정답은 4개예요"), 한 줄 정리 빈칸, 아래 큰 버튼('다음 문항'·'한 줄 정리하기'·'문장 완성하기'), HUD 'MISSION 0N 탐사 N · 제목', 실험실 '문항 n/4', 도감 버튼 잠김(S06).

## 시안과 다른 것
- 태양계 지도·밤하늘·실험실에서는 패널 위 강조 선과 버튼 색이 그 화면의 강조 색(파랑·보라)이다. 시안은 모두 목성 화면이라 주황(기존 강조 색 규칙).
