## 기대 행
- 미션 탭: 탐사 1(1-1~1-4, 흥미1), 탐사 2(2-1~2-3, C-1, 흥미2), 탐사 3(3-1~3-4, 흥미3), 탐사 4(4-1~4-6, C-2, 흥미4, 흥미5) = 24행
  - 1-4 메모: `구성원: 태양, 행성, 위성, 혜성, 소행성 / 요일 도입: 완료`
  - 각 탐사 마지막 문항 행(1-4, 2-3, 3-4, 4-6)에 한 줄 정리
  - C-1 최종 답: `내 이름은 화성. 붉은 옷을 입고 있지. 착륙해도 끄떡없지. 고리는 다른 친구 몫이지.`, 메모 `화성`
  - C-2 최종 답: `이 별자리의 새 이름은 숟가락자리예요. 왜냐하면 손잡이가 달린 모양처럼 보이기 때문이에요.`, 메모 `북두칠성`
- 도감 탭: 행성 8행(수성·금성은 인터넷을 끊은 채 기록 → 다시 연결 뒤 전송)

## 발견해 고친 것
- 다시 보내기가 겹치면(온라인 복귀·선택 화면·버튼) 같은 행을 두 번 보낼 수 있었음 → 한 번만 보냄
- 다시 보내는 중에 새로 실패한 행이 대기열에서 사라질 수 있었음 → 남김
- 여러 행을 한꺼번에 보내면 Apps Script 응답 단계 404가 잦았음(약 절반) → 한 기기에서는 한 행씩 차례로(이후 9행 중 8행 바로 성공, 1행은 다시 보내기로 성공)

## 알아 둘 것
- 점검 초반(위 수정 전)에 보낸 도감 행은 겹쳐 보내져 시트에 같은 행이 더 있을 수 있음. 테스트 학생(4학년 1반 1번 "테스트") 행은 모두 지워도 됨
- Apps Script는 한 행에 몇 초씩 걸림. 404 응답 행은 시트에 이미 적혔을 수도 있어 다시 보내면 겹칠 수 있음(재제출 허용과 같은 취급)
