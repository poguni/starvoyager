# 구글 시트 제출 테스트 (Phase 1)

학교 Google 계정에서 "웹 페이지 → 구글 시트의 '미션'·'도감' 두 탭 기록"이 실제로 되는지 확인하는 테스트입니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 시트에 붙여넣는 Google Apps Script. 제출을 받아 검증하고, 종류에 따라 '미션' 탭 또는 '도감' 탭에 1행을 추가합니다. |
| `test.html` | 테스트용 웹 페이지. '미션 행 보내기', '도감 행 보내기' 두 버튼으로 샘플 1행씩 보냅니다. |
| `Code.test.js` | `npm test`로 `Code.gs`를 컴퓨터에서 미리 검사하는 테스트(시트에 붙여넣지 않음). |

## 1. 시트에 스크립트 붙여넣기

1. 학교 Google 계정으로 로그인하고, **새** 스프레드시트를 하나 만듭니다. (이름 예: `별빛탐사선 결과`, 달빛 관측소 시트와 따로 두기를 권장)
2. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 원래 들어 있는 `function myFunction() {}` 코드를 모두 지우고, `Code.gs`의 내용을 전부 붙여넣습니다.
4. 저장(💾 또는 `Ctrl + S`)합니다. 프로젝트 이름은 아무거나 괜찮습니다.

> 반드시 **시트 안에서** 연 Apps Script여야 합니다. `script.google.com`에서 따로 새 프로젝트를 만들면 시트와 연결되지 않습니다.
>
> '미션'·'도감' 탭은 미리 만들 필요가 없습니다. 첫 제출 때 머리글과 함께 자동으로 생깁니다.

## 2. 웹앱으로 배포하기

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(⚙) 옆 **유형 선택 → 웹 앱**을 고릅니다.
3. 다음과 같이 설정합니다.

   | 항목 | 값 | 이유 |
   |---|---|---|
   | 설명 | `v1` (자유) | 나중에 무엇을 배포했는지 구분하기 위해 |
   | 실행 사용자 | **나** | 시트에 기록하는 일을 선생님 계정의 권한으로 하기 위해. 학생은 시트에 접근할 권한이 없어도 됩니다. |
   | 액세스 권한이 있는 사용자 | **모든 사용자** | 학생이 구글 로그인 없이 접속해도 제출되도록 하기 위해 |

4. **배포**를 누릅니다.
5. 처음이면 **액세스 승인**을 요구합니다. 계정을 고르고, "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**을 누릅니다. (내가 만든 스크립트가 내 시트에 쓰는 것을 허용하는 절차입니다.)
6. 배포가 끝나면 **웹 앱 URL**이 나옵니다. 끝이 `/exec`로 끝나는 주소를 복사해 둡니다.

### 주소가 정상인지 먼저 확인
복사한 주소를 브라우저 주소창에 붙여넣어 열어 보세요. **`정상 작동 중`** 이라는 글자가 보이면 배포가 된 것입니다. 구글 로그인 화면이 나오면 액세스 권한이 "모든 사용자"가 아닌 것입니다.

## 3. test.html로 확인하기

1. `test.html`을 더블클릭해 브라우저에서 엽니다.
2. 맨 위 **웹앱 주소** 칸에 복사한 주소를 붙여넣습니다. (이 브라우저에만 기억되고, 파일에는 저장되지 않아 git에 올라가지 않습니다.)
3. **미션 행 보내기**를 누릅니다.
   - 화면에 **제출됐어요!** 가 나오고, 시트에 `미션` 탭이 생기며 머리글 행과 데이터 1행이 보여야 합니다.
4. **도감 행 보내기**를 누릅니다.
   - 시트에 `도감` 탭이 생기며 머리글 행과 데이터 1행이 보여야 합니다.
5. 잘못된 값으로도 눌러 봅니다. 아래 예시마다 **제출하지 못했어요. 이유: …** 가 나오고 시트에는 행이 늘어나지 않아야 합니다.
   - 학년 `9` → "학년은 1~6 숫자로 써 주세요."
   - 문항 `5-1` 또는 `흥미6` → "알 수 없는 문항이에요."
   - 행성 `명왕성` → "알 수 없는 행성이에요."

## 4. 앱에 주소 넣기 (.env)

프로젝트 폴더의 `.env.example`을 복사해 `.env`를 만들고, 주소를 넣습니다.

```
VITE_WEBAPP_URL=https://script.google.com/macros/s/.../exec
```

`.env`는 `.gitignore`에 들어 있어 git에 올라가지 않습니다. (배포할 때는 GitHub 저장소 Variables에 같은 값을 넣습니다. Phase 10)

## 5. 화면 메시지와 원인

| 화면 메시지 | 원인 |
|---|---|
| 웹앱 주소가 비어 있어요 | 맨 위 칸에 주소를 넣지 않았음 |
| 서버에 연결하지 못했어요 | 인터넷 끊김, 주소 오타, 또는 액세스 권한이 막혀 브라우저가 응답을 받지 못함 |
| 답이 올바르지 않아요 (구글 로그인 화면 내용이 보임) | 액세스 권한이 "모든 사용자"가 아님, 또는 주소 끝이 `/exec`가 아님 |
| 제출하지 못했어요. 이유: … | 입력값이 검증에서 걸림. 이유는 문구 그대로 |

## 6. 코드를 고친 뒤 다시 배포하기

`Code.gs`를 고쳤다면 **배포 → 배포 관리 → 연필(✎) → 버전: 새 버전 → 배포**를 합니다. 이렇게 하면 웹앱 주소가 그대로 유지됩니다. (**새 배포**를 누르면 주소가 바뀝니다.)

## 7. 보안 유의사항

- 웹앱 주소를 아는 사람은 누구나 제출할 수 있습니다. 그래서 `Code.gs`는 학년·반·번호·이름·탐사·문항·행성을 검사해서 형식이 틀리면 기록하지 않고, 글 길이를 200자로 제한합니다. `=`, `+`, `-`, `@`로 시작하는 글은 시트에서 수식으로 실행되지 않도록 처리합니다.
- 이 웹앱은 시트를 **읽어서 돌려주지 않습니다**(`doGet`은 `정상 작동 중`만 돌려줍니다). 시트는 선생님 계정에서만 볼 수 있습니다.
- 여러 학생이 동시에 제출해도 `LockService`로 한 번에 한 줄씩 기록합니다.
- 주소가 공개 페이지의 코드에 들어가므로, 누가 제출했는지를 완벽히 증명할 수는 없습니다. 이 앱은 성적 처리용이 아니라 수업 중 관찰 결과를 모으는 용도입니다.
- 학생 이름이 선생님의 구글 계정에 저장됩니다. 학교의 개인정보 처리 지침에 맞는지 확인해 주세요.
