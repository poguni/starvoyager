# 별빛 탐사선 연출 메모

> 시간 값은 `tokens.css`의 `--sv-dur-*` 변수와 맞춘다. '움직임 줄이기'를 켠 기기(prefers-reduced-motion)에서는 흔들림과 큰 이동을 생략한다.

## 공통
- 기본 이징: ease-in-out (`--sv-ease`, 부드럽게 시작하고 부드럽게 멈춤)
- 화면 요소 등장: 0.2~0.3초 페이드 + 8px 이동
- 강조 색 전환: 0.6초 동안 이전 색에서 새 색으로 (`--sv-dur-accent`)

## 비행 (천체 누르기, 이전/다음 행성)
- 2~3초. 출발할 때 HUD 상단에 "○○(으)로 이동 중", 도착하면 목적지 이름이 바뀌며 강조 색 전환
- 비행 중에는 하단 버튼이 흐려지고 눌리지 않음(잠김 상태)

## 착륙
- 단단한 땅 행성: 약 6초 하강 → 땅 가까이에서 멈춤 → HUD 중앙에 "단단한 땅에 착륙했어요!" 배너(2초) → '다시 올라가기' 버튼 등장
- 금성: 하강 중간 2초 동안 노란 구름 통과
- 기체 행성: 약 8초 하강하며 구름이 점점 짙어짐 → 땅이 나오지 않은 채 멈칫 → "내려앉을 땅이 없어요. 표면이 기체로 되어 있어요." 배너 → 자동으로 3초 동안 다시 올라옴
- 한 번의 착륙 연출은 12초를 넘지 않는다
- 착륙 중 HUD 테두리가 아주 약하게 흔들림(선택, 움직임 줄이기에서는 생략)

## 도감
- 도감 펼치기/접기: 오른쪽에서 0.35초 미끄러져 들어옴(크롬북은 아래에서)
- 틀린 칸: 0.4초 좌우로 작게 흔들림 + 주의 색(`--sv-warn`) 테두리
- 완성 도장: 0.3초 커졌다가 제자리에 '쿵' 하고 찍힘(살짝 기울어짐), 이어서 교과서 문장이 0.3초 페이드인
- 완성 개수 숫자: 하나 늘어날 때 잠깐 커졌다 돌아옴

## 미션
- 정답 배너 "정답이에요!": 위에서 내려오며 1.5초 머무름
- 오답: 고른 보기만 작게 흔들림, 힌트 상자가 펼쳐짐
- 한 줄 정리 완성: 완성된 문장이 패널 가운데에 크게 0.5초 페이드인

## 끌어다 놓기
- 집은 카드는 살짝 커지고 그림자가 짙어짐, 놓을 수 있는 칸은 테두리가 밝아짐
- 확인 후 틀린 카드: 0.4초 흔들림. 2차 실패 시 카드들이 1초 동안 정답 자리로 이동

## 북쪽 밤하늘
- 별 잇기: 선이 0.3초 동안 그어짐. 잘못 누른 별은 작게 흔들림
- 별자리 완성: 선화가 1초 동안 은은하게 나타나고 이름표 등장
- 힌트: 다음 별이 1초 주기로 두 번 반짝임
- 주변 불빛: 1초 동안 지평선이 밝아지며 어두운 별부터 사라짐
