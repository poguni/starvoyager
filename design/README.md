# 별빛 탐사선 디자인 자료 (design/)

- 확정 방향: **A. 차분한 관제실형** (2026-10-07)
  가는 선, 반투명 유리 패널, 화면 네 모서리 꺾쇠, 계기판 숫자 글꼴, 밝은 모눈 노트 도감
- 기준 화면: 전자칠판 1920×1080, 크롬북 1366×768
- 만든 곳: Claude 디자인 캔버스 「별빛 탐사선 디자인 시안」(방향 비교) → 이 폴더(확정본)

## Claude Code가 지킬 우선순위
1. **내용**(문구, 보기, 정답, 기능, 흐름)은 `별빛탐사선_기획서.md`가 기준이다.
2. **겉모습**(색, 글꼴, 크기, 간격, 모양, 움직임)은 이 폴더가 기준이다.
3. 색·크기·간격은 `tokens.css`의 변수만 쓴다. 코드에 색상값을 직접 쓰지 않는다.
4. 화면 요소의 모양은 `components.css`의 클래스를 그대로 쓰거나 고쳐 쓴다. 새 클래스를 만들 때도 값은 토큰으로.
5. 시안에 없는 화면·상태는 이 디자인 시스템으로 만들되, **만들기 전에 모양을 먼저 보여 주고 묻는다.**
6. 시안의 3D 자리(그라데이션 원, 줄무늬 원, 별 점)는 자리 표시용이다. 앱에서는 Three.js 장면이 들어가며, 이 자리표시는 옮기지 않는다(`.sv-ph-*` 클래스는 앱에 넣지 않는다).
7. 시안과 다르게 만든 것은 아래 '디자인과 다르게 정한 것' 표에 적는다.

## 폴더 구성
```
design/
├─ README.md            ← 이 문서
├─ tokens.css           ← 디자인 토큰(색·글꼴·크기·간격·강조 색 11개·크롬북 값)
├─ components.css       ← 공통 부품 CSS(HUD, 조작 버튼, 도감, 미션 패널, 끌어다 놓기, 슬라이더 등)
├─ motion.md            ← 움직임 길이와 방식
├─ fonts/               ← Pretendard(가변), IBM Plex Mono 500·600 + 라이선스(둘 다 SIL OFL)
├─ icons/
│  ├─ icons.svg         ← 아이콘 스프라이트(앱에서 사용)
│  └─ icons.js          ← 시안 HTML 전용 로더(앱에서는 쓰지 않음)
├─ html/                ← 시안 원본 HTML(브라우저로 바로 열림). 실제 클래스·구조의 참고용
└─ screens/             ← 시안 PNG(같은 이름). Claude Code가 이미지로 보고 대조
```

## 핵심 규칙 요약
- **강조 색 전환**: 앱 최상위 요소에 `data-accent="mars"`처럼 붙이면 HUD 목적지·꺾쇠·선택된 보기·주요 버튼·도감 머리띠가 함께 바뀐다. 값은 `default, sun, mercury, venus, earth, mars, jupiter, saturn, uranus, neptune, sky`. 전환 시간은 0.6초.
- **상태 표시는 접근성 속성으로**: 선택됨·켜짐 `aria-pressed="true"`, 잠김 `disabled`, 틀림 `.is-wrong`, 맞음 `.is-correct`, 눌러 보라는 안내 `.is-cue`, 놓을 수 있는 칸 `.is-target`, 집은 카드 `.is-dragging`.
- **오답 색은 주황**(빨강 아님, 색약 배려). 틀린 보기에는 색과 함께 '다시 봐요'/'틀렸어요' 글자가 붙는다.
- **색 견본은 항상 글자와 함께** 쓴다.
- **글씨 최소 크기**: 전자칠판 18px, 크롬북 14px. 도감 보기는 21px(두 줄까지), 미션 보기는 24px.
- **누르는 크기**: 최소 48px. 도감 보기 48px, 미션 보기 72px, 하단 조작 버튼 104px(크롬북 64px).
- **해왕성만** 강조 색 위 글씨가 흰색이다(`--sv-on-accent`가 알아서 바뀜).
- **오답 확인 단계**(S06): 처음 고른 오답에는 '틀렸어요' 표시가 남고, 보기를 다시 누를 수 있다. 두 번째로 고른 답이 최종 답이다. 별도의 '다시 고르기' 버튼은 두지 않는다.
- **크롬북**: 화면 폭 1440px 이하에서 `tokens.css`의 크롬북 값이 자동 적용된다. 도감은 오른쪽 패널 대신 아래에서 올라오는 패널(화면 높이의 약 47%), 하단 조작 버튼은 그 위에 붙는다.
- **S08 별 위치는 모양을 보여 주기 위한 대략값**이다. 실제 별 위치는 Phase 7의 별 데이터와 천문 계산으로 정한다. 큰곰 선화도 자리만 표시했으며 Phase 7에서 직접 그린다.

## Claude Code에서 쓰는 방법
- Phase 1: `tokens.css` → `src/styles/tokens.css`, `components.css` → `src/styles/components.css`, `fonts/` → `public/fonts/`(또는 `src/assets/fonts/`), `icons/icons.svg` → `public/icons.svg`로 옮긴다. 옮긴 뒤 `@font-face` 경로만 새 위치에 맞게 고친다. `icons.js`와 `.sv-ph-*` 규칙은 옮기지 않는다.
- 각 Phase: 해당 시안 `screens/Sxx.png`를 열어 보고, 필요하면 `html/Sxx.html`에서 구조와 클래스를 확인한 뒤 만든다. 만든 화면은 같은 크기로 스크린샷을 찍어 시안과 나란히 비교한다.
- 시안 HTML을 브라우저에서 보려면 `html/` 안의 파일을 더블클릭하면 된다(인터넷 없이 열림).
