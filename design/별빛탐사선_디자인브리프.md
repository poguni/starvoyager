# 별빛 탐사선 (Star Voyager) 디자인 브리프 · 클로드 디자인 프롬프트

> 기준 문서: `별빛탐사선_기획서.md` (특히 5장 화면 구성과 디자인, 8장 탐사 도감, 9장 미션)
> 목적: 클로드 디자인으로 2D 화면 요소(조종석 HUD, 도감, 미션 패널 등)의 시안과 디자인 시스템을 만들고, 그 결과를 Claude Code에 넘긴다.

---

## 0. 이 문서 사용법

### 0-1. 핵심 원칙: 두 층으로 나누어 디자인한다
- **아래층(3D 장면)**: 행성·별·빛무리. 클로드 디자인에서는 그리지 않는다. **배경 이미지로 대신**한다.
- **위층(2D 화면 요소)**: 조종석 테두리, 상단 계기판, 하단 조작 패널, 도감, 미션 패널, 버튼. **이것만 디자인한다.** 실제 앱에서도 HTML·CSS로 만들어 3D 위에 겹친다.

### 0-2. 준비물: 3D 자리에 깔 배경 이미지
아래 중 편한 방법을 고른다.
- **방법 A (추천)**: 실제 느낌에 가까운 이미지 몇 장을 준비해 클로드 디자인에 첨부한다.
  - 화성·해왕성·목성·토성 사진: NASA 공개 사진(대부분 퍼블릭 도메인)을 내려받는다. 검은 우주 배경에 행성이 화면 왼쪽~가운데에 있는 사진이 좋다.
  - 태양계 전체·밤하늘: 달빛 관측소의 우주 시점·밤하늘 화면을 전자칠판 크기로 캡처해 쓴다.
- **방법 B (간단)**: 이미지 없이, 프롬프트에 있는 대로 클로드 디자인이 "어두운 우주 그라데이션 + 행성 색 원형 그라데이션"으로 자리만 표시하게 한다.

### 0-3. 진행 순서
| 단계 | 내용 | 붙여 넣을 프롬프트 |
|---|---|---|
| 0 | 브리프 전달 | 1장 |
| 1 | 방향 시안 3개 비교 → 하나 고르기 | 2장 |
| 2 | 디자인 시스템 확정 | 3장 |
| 3 | 핵심 화면 10개 | 4장 (네 번에 나누어) |
| 4 | 연출 메모 | 5장 (클로드 디자인 없이 파일로 저장) |
| 5 | 내보내기 → `design/` 폴더 정리 | 6장 |

- 각 단계의 결과가 마음에 들 때까지 클로드 디자인 안에서 수정을 주고받은 뒤 다음 단계로 간다.
- 한 대화(프로젝트) 안에서 1 → 3단계를 이어서 진행해야 앞에서 정한 방향과 디자인 시스템이 유지된다.

## 1. 브리프 (맨 처음 한 번 붙여 넣기)

```
초등학교 4학년 과학 수업용 3D 웹 앱 「별빛 탐사선(Star Voyager)」의 화면 디자인을 함께 만들려고 해요. 먼저 아래 브리프를 읽고 내용을 이해했는지 짧게 요약만 해 주세요. 시안은 다음 메시지부터 요청할게요.

[앱 소개]
- 학생이 탐사선을 타고 태양계를 날아다니며 태양과 행성 8개를 실사 3D로 관찰하고, 관찰한 특징(색깔, 표면 상태, 고리, 그 밖의 특징)을 '탐사 도감'에 기록해 완성합니다. 마지막에는 지구로 돌아와 북쪽 밤하늘에서 북극성과 별자리를 찾습니다.
- 수업 3~4차시에 걸쳐 쓰는 주교재입니다. 예측 → 관찰 → 정답 확인으로 이어지는 미션이 있습니다.
- 자매 앱 「달빛 관측소」(달 관찰 앱)와 같은 시리즈입니다.

[사용자와 기기]
- 학생: 초등 4학년(10~11세). 짧은 글, 큰 버튼이 필요합니다.
- 교사: 전자칠판으로 시연합니다.
- 기준 화면 1: 전자칠판 1920×1080 (교실 뒤에서도 읽혀야 함, 터치)
- 기준 화면 2: 크롬북 1366×768 (학생 개인 탐사, 터치패드·터치)

[화면 구조: 두 층]
- 아래층은 Three.js로 그리는 3D 장면(행성, 별, 빛무리)입니다. 시안에서는 그리지 말고, 제가 첨부하는 배경 이미지를 깔거나, 이미지가 없으면 어두운 우주 그라데이션 위에 행성 색의 원형 그라데이션으로 자리만 표시해 주세요.
- 위층은 HTML·CSS로 만드는 2D 화면 요소입니다. 이번에 디자인할 것은 이 위층입니다.
  · 조종석 HUD: 화면 가장자리의 얇은 계기판 테두리, 상단 계기판(현재 탐사, 목적지 이름, 도감 완성 개수), 하단 조작 패널(큰 버튼)
  · 탐사 도감: 오른쪽에서 펼쳐지는 종이 노트 느낌의 패널(크롬북 크기에서는 아래에서 올라오는 패널)
  · 미션 패널: 도감 자리에 나타나는 질문·보기·힌트·정답 배너
  · 그 밖에: 학생 등록 화면, 탐사 선택 화면, 끌어다 놓기 카드, 시각 슬라이더, 발표 화면

[디자인 방향]
- "3D 화면은 우주선 조종석, 기록은 탐험가의 도감." 두 느낌을 섞습니다.
- HUD는 3D 장면을 가리지 않도록 가늘고 반투명하게. 도감은 따뜻한 종이 질감으로 대비를 줍니다.
- 가까이 간 천체에 따라 HUD 테두리·버튼·도감 머리띠의 '강조 색'이 바뀝니다.
  태양 #FFB547 / 수성 #A8A29E / 금성 #E8C468 / 지구 #4A90E2 / 화성 #E0603A / 목성 #D9A066 / 토성 #E6CF8B / 천왕성 #6FD3D0 / 해왕성 #3D6BE0 / 북쪽 밤하늘 #7C8CF8 / 태양계 지도·크기 비교는 기본 강조 색(제안해 주세요)
- 바탕은 어두운 우주색(남색 계열), 글씨는 밝은색.

[지켜야 할 조건]
- 글꼴: 한글 가독성이 좋은 공개 글꼴(예: Pretendard). 전자칠판 본문 최소 24px, 크롬북 본문 최소 16px.
- 누르는 요소는 최소 48×48px(전자칠판에서는 더 크게).
- 강조 색 위의 글씨는 명도 대비 4.5:1 이상. 색만으로 정보를 전달하지 않고 항상 이름·아이콘을 함께 둡니다.
- 학생에게 보이는 문구는 짧은 해요체. 교과서 용어만 씁니다(충돌 구덩이, 행성, 위성, 혜성, 소행성, 별, 별자리). '크레이터', '가스 행성' 같은 말은 쓰지 않습니다.
- 실제 기관·기업의 로고나 이름, 기존 캐릭터를 쓰지 않습니다. 아이콘과 그림은 모두 새로 만든 단순한 형태로.
- 실제 앱에서는 HTML·CSS로 구현하므로, 그림자·블러·그라데이션·테두리 등 CSS로 만들 수 있는 표현을 씁니다.
```

## 2. 단계 1 — 방향 시안 3개 (화면 하나로 비교)

**첨부**: 화성 사진(또는 배경 이미지) 1장

```
첫 번째 요청입니다. 디자인 방향을 고르기 위해, 같은 화면 하나를 서로 다른 세 가지 방향으로 만들어 주세요.

[화면] 화성 탐사 중 + 탐사 도감 펼침 (전자칠판 1920×1080)
- 배경: 첨부한 화성 이미지(없으면 붉은 원형 그라데이션)가 화면 왼쪽~가운데에 크게
- 강조 색: 화성 #E0603A
- 상단 계기판: "탐사 2 · 행성 탐사" / 목적지 "화성" / 도감 "5/8"
- 하단 조작 패널 버튼: 태양계 지도, ◀ 이전 행성, 다음 행성 ▶, 착륙하기, 고리 찾기, 이름 보기, 도감
- 오른쪽 도감 패널(화성 카드, 작성 중 상태):
  · 머리띠: "화성"
  · 색깔(하나 고르기, 작은 색 견본 + 글자): 회색 / 노란색 / 파란색 바다와 초록·갈색 땅 / 붉은색(선택됨) / 흰색과 갈색 줄무늬 / 연한 갈색 / 청록색 / 파란색
  · 표면 상태: 단단한 땅(선택됨) / 기체
  · 고리: 뚜렷한 고리가 있어요 / 희미한 고리가 있어요 / 고리가 없어요(선택됨)
  · 그 밖의 특징(여러 개 고르기): 충돌 구덩이가 많아요 / 표면이 얼룩져 보여요 / 바다와 육지가 있어요 / 줄무늬가 있어요 / 행성 중 가장 커요 / 행성 중 가장 작아요
  · 버튼: "도감에 기록하기"

[세 가지 방향]
A. 차분한 관제실형: 아주 가는 선, 반투명 유리 패널, 모서리 꺾쇠 장식, 숫자는 계기판 느낌. 도감은 깔끔한 모눈 노트.
B. 장난감 우주선형: 둥근 모서리, 도톰한 테두리, 친근한 아이콘, 버튼이 손에 잡힐 듯한 입체감. 도감은 스티커를 붙이는 수첩.
C. 탐험가 노트형: HUD는 아주 최소한, 도감이 크고 주인공. 바랜 종이, 손으로 붙인 듯한 사진 테두리, 도장.

세 시안을 나란히 볼 수 있게 보여 주시고, 각 방향의 장단점을 4학년 사용자와 전자칠판 가독성 관점에서 두세 줄씩 정리해 주세요.
```

**고른 뒤 이어서 보낼 말 (예시)**
```
B 방향으로 가겠습니다. 다만 HUD 테두리는 A처럼 더 가늘고 반투명하게, 도감은 C의 종이 질감과 도장을 섞어 주세요. 이 기준으로 같은 화면을 한 번 더 다듬어 주세요.
```

## 3. 단계 2 — 디자인 시스템 확정

```
고른 방향으로 디자인 시스템을 정리해 주세요. 디자인 시스템으로 저장할 수 있으면 저장해 주세요. 한 페이지에서 모두 볼 수 있게 보여 주세요.

1. 색
   - 바탕(우주색) 단계, 패널, 글씨(기본·보조·흐림), 성공(정답)·주의(오답 힌트)·정보 색
   - 강조 색 11개(천체 10개 + 기본): 각각 강조 색, 강조 색 위 글씨 색, 옅은 배경용 색. 대비 4.5:1 이상인지 표시
   - 도감 종이색, 종이 위 글씨 색, 도장 색
2. 글꼴과 글씨 크기
   - 한글 글꼴(예: Pretendard), 계기판 숫자용 글꼴(선택)
   - 전자칠판 / 크롬북 각각의 크기 단계: 화면 제목, 패널 제목, 본문, 보기, 버튼, 작은 안내
3. 간격·모서리·그림자·블러 단계
4. 부품 (상태별로: 기본 / 눌렀을 때 / 선택됨 / 잠김 / 비활성)
   - 하단 조작 버튼, 토글 버튼(이름 보기 등), 큰 주요 버튼("도감에 기록하기")
   - HUD 조각: 테두리 모서리, 상단 계기판 칸, 비행 중 표시("화성으로 이동 중")
   - 도감: 패널 틀, 머리띠, 하나 고르기 보기, 여러 개 고르기 보기, 색 견본 보기, 틀린 칸 표시(정답은 숨김) + 힌트, 완성 도장, 완성 개수 표시
   - 미션 패널: 질문, 보기 버튼, 힌트 상자, 정답 배너("정답이에요!"), 정답 공개 상자, 한 줄 정리 빈칸 문장
   - 끌어다 놓기 카드(행성 이름 + 작은 원)와 놓는 칸·상자, 틀린 카드 표시
   - 시각 슬라이더(저녁 6시 ~ 아침 6시), 진행 표시, 발견 카드(짧은 안내 팝업), 확인 대화 상자
   - 아이콘 세트: 태양계 지도, 이전/다음, 착륙, 다시 올라가기, 고리 찾기(돋보기), 이름 보기, 도감, 재생/일시정지, 태양 빛 가리기, 주변 불빛, 힌트, 지우기, 발표하기, 닫기
5. 강조 색이 바뀌는 예: 같은 버튼과 도감 머리띠를 화성 / 해왕성 / 북쪽 밤하늘 색으로 나란히

마지막으로, 이 디자인 시스템의 값을 CSS 변수로 정리한 코드(:root에 색·글꼴·크기·간격·모서리·그림자, 그리고 [data-accent="mars"] 같은 강조 색 묶음 11개)를 tokens.css 파일 내용으로 따로 보여 주세요. 이 파일은 개발 도구에 그대로 넘길 예정입니다.
```

## 4. 단계 3 — 핵심 화면 10개

한 번에 2~3개씩 네 번에 나누어 요청한다. 모든 화면은 단계 2의 디자인 시스템을 따른다. 화면 번호(S01~S10)는 나중에 파일 이름과 Claude Code 프롬프트에서 그대로 쓴다.

### 4-1. 첫 묶음: S01, S02, S03

**첨부**: 태양계 전체 느낌의 배경 이미지(달빛 관측소 우주 시점 캡처 등)

```
디자인 시스템을 따라 화면 세 개를 전자칠판 1920×1080으로 만들어 주세요. 화면 이름 앞의 번호(S01~S03)를 시안 제목에 꼭 붙여 주세요.

S01. 탐사 대원 등록 (앱 첫 화면)
- 배경: 별이 있는 어두운 우주, 가운데에 등록 카드
- 제목 "별빛 탐사선", 부제 "탐사 대원 등록"
- 입력: 학년(1~6), 반, 번호, 이름 — 숫자는 크게 고르기 쉬운 방식으로 제안해 주세요
- 버튼 "탐사 시작하기"
- 입력 오류 예시 하나: 이름이 비었을 때 "이름을 적어 주세요."

S02. 탐사 선택
- 상단: "○학년 ○반 ○번 ○○○ 대원" + 작은 버튼 "다른 친구가 사용해요"
- 탐사 카드 4장(각각 큰 그림 아이콘, 제목, 한 줄 설명, 진행 상태)
  · 탐사 1 「태양계 구성원과 태양」 — 완료
  · 탐사 2 「행성 탐사와 도감」 — 진행 중 (도감 5/8)
  · 탐사 3 「크기 비교 실험실」 — 시작 전
  · 탐사 4 「북쪽 밤하늘 별자리」 — 시작 전
```
